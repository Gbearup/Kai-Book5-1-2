國中英語 Core Grammar Review

國一核心文法重點整理

含 be 動詞句型、祈使句、Where與地點介系詞、There is/are 存在句、現在進行式、時間詢問與助動詞 Can 的詳細結構解析與例句。

重點 1

be 動詞句型與 Who 疑問句

公式：
1. Be + 主詞 + a/an/所有格 + 單數名詞?
   ➔ Yes, 主詞 + be. / No, 代名詞 + be + not.
2. Who + be + 主詞? ➔ 主詞 + be + 姓名/關係.

例 1： A: Is Julie a singer?
        B: No, she's not. (不，她不是。)

例 2： A: Is Eva a cute girl?
        B: Yes, she is. (是的，她是。)

例 3： A: Who is that boy?
        B: He is Noah. (他是 Noah。)

重點 2

指示代名詞 (This/That/These/Those)

公式：
1. What + is + this / that / it? ➔ This / That / It + is + 冠詞 + 單數名詞.
2. What + are + these / those / they? ➔ These / Those / They + are + 複數名詞.

例 1： A: What is that?
        B: That / It is an eraser. (那是一個橡皮擦。)

例 2： A: What are these?
        B: These / They are tigers. (這些是老虎。)

句型擴充： What about the blue dress? (這件藍色洋裝怎麼樣？) ➔ It's so cool.

重點 3

祈使句與 Let's 提議句型

公式：
1. (Don't +) 原形動詞...
2. Please + 原形動詞, 人名. / 人名, please + 原形動詞.
3. Let's (+ not) + 原形動詞...

例 1： Come here. (過來這裡。) / Don't be sad. (不要難過。)

例 2： Please be quiet, Sam. = Sam, please be quiet. (Sam，請安靜。)

例 3： Let's go to the zoo. (我們去動物園吧。)
        Let's not upload the photos. (我們不要上傳照片吧。)

重點 4

Where 疑問句與介系詞

公式：
1. Where + be + 主詞?
2. 主詞 + be + 介系詞 + the / 所有格 + 名詞.

例句：
A: Where is my blanket? (我的毛毯在哪裡？)
B: It is on the bed. (它在床上。)

💡 常見介系詞：in (在...裡面), on (在...上面), under (在...下面), in front of (在...前面)

重點 5

There is / There are (存在句型)

公式：
肯定：There is + a(n) 單數名詞 / There are + 數字/some + 複數名詞.
否定：There isn't + a(n) 名詞 / There aren't + 數字/any + 複數名詞.
問句：Is / Are there + any + 名詞 + 地點?

例 1： There is a blanket on the bed. / There are some books on the desk.

例 2： There isn't a polar bear in the zoo. / There aren't any students in the classroom.

例 3： A: Are there any children on the sports field?
        B: Yes, there are.

重點 6

現在進行式 & 時間與星期詢問

公式：
1. Be + 主詞 + V-ing? ➔ Yes, 主詞 + be. / No, 主詞 + be + not.
2. What + be + 主詞 + doing? ➔ 主詞 + be + V-ing.
3. What time + is + 主詞? ➔ It is at + 時間.
4. What day + is + 主詞? ➔ It is on + 星期.

例 1： Is Jennifer reading? ➔ No, she is not.

例 2： What is Leo doing? ➔ He is cooking. (他正在煮飯。)

例 3： What time is the English class? ➔ It's at ten o'clock.

例 4： What day is the group chat? ➔ It is on Tuesday.

重點 7

助動詞 Can 的用法

公式：
1. Can + 主詞 + 原形動詞...?
   ➔ Yes, 主詞 + can. / No, 主詞 + can't.
2. What + can + 主詞 + 原形動詞...? ➔ 主詞 + can + 原形動詞.

例 1： A: Can your cat shake hands? (你的貓會握手嗎？)
        B: No, it can't. (不，牠不會。)

例 2： A: What can Juliet do? (Juliet 會做什麼？)
        B: She can take photos. (她會拍照。)
